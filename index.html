Générateur de Déclencheurs Automatiques (Installable Triggers)

Automatisez l'exécution périodique ou événementielle de votre script
Code du déclencheur à injecter 
function installerDeclencheurAutomatique() {
  ScriptApp.newTrigger('lancerNettoyageAutomatique')
    .timeBased()
    .everyDays(1)
    .atHour(2)
    .create();
  console.info("✅ Déclencheur quotidien configuré pour 02h00.");
}
