# ⚡ Interdevappscript — Universal AI Studio & Development Hub

> **Interdevappscript** est un atelier de développement web universel connecté à Google AI Studio (Google Gemini GenAI SDK), React 19, TypeScript, Tailwind CSS v4 et Vite.

---

## 🚀 Capacités Multi-Environnements

1. ⚡ **Apps Script Hub** : Console de consultation, tests et copie rapide de vos scripts Google Apps Script (`cleanUp`, `Export_titre_mail`, `Gmail_Rules`, `Drive_Scanner`).
2. 🐍 **Python & Automation Lab** : Génération de scripts Python autonomes (standard library, traitement de données, scrapers).
3. 🗄️ **SQL & Cloudflare D1 Lab** : Générateur de schémas et requêtes pour bases SQLite / Cloudflare D1 (intégré à `Bullix`).
4. 📱 **Mobile & KMP Lab** : Snippets d'UI Jetpack Compose & logique métier Kotlin Multiplatform (pour `Needix` et `InstallAPK`).
5. 🤖 **Google AI Studio Sandbox** : Bac à sable direct pour formuler et tester vos prompts IA via `@google/genai`.

---

## 🛠️ Commandes Locales

```bash
# Installation des dépendances
npm install

# Démarrage du serveur de développement (port 3000)
npm run dev

# Build de production
npm run build
```
